Lesson 02 • Computer components

⌨️ Input and Output Devices

How do we send information to a computer — and how does it send information back to us? Let's find out!

🌟 Welcome to Lesson 2!

In this lesson, you will discover the devices that help us communicate with computers. Get ready to explore!

🎯 Learning goals

✓ Explain what input devices do
✓ Identify common output devices
✓ Tell the difference between input and output

📘 What are input and output devices?

Input and output devices are important parts of a computer. They help us communicate with it. Input devices enter data and instructions into a computer. Output devices show or produce information after the computer has processed data.

🔵 Input devices — sending data in

What is an input device?

An input device is a piece of hardware that allows a user to enter data or instructions into a computer. We use input devices to type, point, scan, record sound and more.

⌨️KeyboardTypes letters, numbers and symbols.
🖱️MouseMoves the pointer and selects items.
🖨️ScannerCopies paper pictures and documents into digital form.
🎙️MicrophoneRecords voice and other sounds.
📷WebcamCaptures photos and live video.
👆TouchscreenAccepts input when you tap or swipe the screen.

🟣 Output devices — showing results

What is an output device?

An output device is hardware that presents the results of computer processing. Output can be visual (what we see), audio (what we hear), or printed on paper.

🖥️MonitorDisplays text, pictures and videos.
🖨️PrinterProduces a paper copy of a document or picture.
🔊SpeakersPlay music, alerts and other sounds.
📽️ProjectorShows a computer image on a large screen.
🎧HeadphonesLet one person listen to audio.
🖨️PlotterPrints large, detailed drawings and plans.

🔄 How do they work together?

A computer uses input devices to receive data. It processes the data and then uses output devices to show the result. For example, when you type a sentence, the keyboard sends your letters to the computer and the monitor displays them.

⭐ Lesson 2 summary
✓ Input devices send data and instructions to a computer.
✓ Output devices show or produce information from a computer.
✓ A keyboard, mouse, scanner and microphone are input devices.
✓ A monitor, printer, speaker and projector are output devices.
✓ Both types help us communicate with computers.
🏆 Fun fact: A touchscreen can work as both an input device and an output device! It displays information and also detects your taps.

📝 Quick quiz

Think of your answer, then open each question to check!

1. Is a keyboard an input or output device?
Input device — it sends the letters and numbers you type to the computer.
2. Which output device produces sound?
Speakers or headphones.
3. What does a scanner do?
It copies pictures or documents from paper into a computer in digital form.
4. Why can a touchscreen be both input and output?
It displays information (output) and detects your taps and swipes (input).
